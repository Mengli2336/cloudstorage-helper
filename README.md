# 梦幻之屿云仓辅助

**Cloud Storage Helper** 是面向 Minecraft 26.1.2 / Fabric 的梦幻之屿服务器云仓辅助模组。
它通过服务器的 `ci` 指令同步云仓数据，让你不必反复打开云仓界面，就能直接查看库存并取出物品。

## 功能

- 在 REI、JEI 的物品列表和书签中直接显示云仓数量。
- 支持取出 1 个、一组或自定义数量，取出数量会自动限制为云仓实际可用数量。
- 支持普通物品与潜影盒。
- 在世界中 `鼠标侧键` 对准方块、掉落物或 Litematica 投影，即可快速取出对应物品。
- 支持自动补货：为物品开启自动补货并设置阈值与目标数量，背包低于阈值时自动从云仓补齐；开启的物品在物品列表中显示星标。
- 在 Litematica 材料列表中增加「云仓」「缺口」两列，缺口 = 总需求 − 云仓。
- 配置与热键基于 MaLiLib，所有按键均可重新绑定。
- 兼容 REI 配方界面导航，返回时不会卡在配方页与数量输入页之间。
- 提供云仓数据刷新、打开存入界面、显示或隐藏云仓返回消息等配置项。

## 安装

1. 为 Minecraft 26.1.2 安装 Fabric Loader。
2. 将本模组与 MaLiLib 放入 `mods` 文件夹。
3. 按需安装 REI、JEI、Litematica 或 Mod Menu。
4. 若曾安装旧版 `cloudstorage-rei`，请先删除对应 jar，避免同一功能被加载两次。

## 默认按键

| 按键 | 功能 |
| --- | --- |
| `V` | 刷新云仓数据 |
| `B` | 打开云仓存入指令 |
| `A` → `Y` | 打开 MaLiLib 配置界面 |
| `Shift + 左键` | 从物品管理器条目取出 1 个 |
| `Shift + 右键` | 从 JEI 或 REI 物品列表取出一组 |
| `鼠标侧键`（世界中） | 快速取出准星所指的物品实体、方块或 Litematica 投影方块 |
| `中键`（JEI 或 REI 列表） | 打开自定义数量界面 |

所有按键均可在 MaLiLib 配置界面中修改。取 1 个、取一组、自定义数量都是完整的 MaLiLib 热键，因此可以使用键盘与鼠标组合，替代旧版的「修饰键 + 鼠标键」设置。

准星快速取出始终按目标物品的最大堆叠数请求；当云仓剩余不足一组时，回退为本地已知的云仓数量。GUI 打开时快速取出会被禁用，物品管理器条目的修饰键点击仍然可用。

## 配置

配置文件位于 `config/cloudstorage-helper.json`。

## 自动补货

1. 在物品管理器条目的自定义数量界面点击「补货设置」，或点击容器界面左侧补货面板中的条目。
2. 点击「自动补货：关」将其开启，然后设置「低于此数量补货」与「补货到」。开启的物品会在 REI / JEI 列表左上角显示星标，并加入补货面板。
3. 未打开任何界面时，模组按扫描间隔检查背包（背包 + 快捷栏 + 副手，不含盔甲槽），数量低于阈值就补到目标数量。
4. 背包满时补货暂停，并在面板上提示；面板上的「立即补一次」不受间隔、开关与冷却限制。
5. 取货请求与手动取货共用服务器 5 条/秒的指令队列，同一物品有 60 tick 冷却。

补货配置项位于配置界面的「补货」页签（含面板缩放、X / Y 偏移），自动补货物品列表保存在配置文件的 `Restock` 段。面板默认贴在容器界面左下角，可整体缩放并可向任意方向偏移。

REI 配方界面由自定义数量界面提供支持：其返回状态与 REI 的导航栈相互隔离，按 Escape 返回配方，使用 REI 的后退操作可回到原来的容器界面。

## 投影材料列表

Litematica 材料列表右侧会额外显示两列：

- **云仓**：该物品在云仓中的数量，达到总需求时显示绿色，否则红色。
- **缺口**：总需求 − 云仓（不会小于 0），为 0 时绿色，否则红色。

数字跟随材料列表自己的倍数设置。云仓数据来自最近一次成功同步的结果，按 `V` 刷新云仓数据后列表中的数字会立即更新，不需要重新打开材料列表。

该功能可在配置界面「兼容性」页签的「投影材料列表显示云仓」中关闭；未安装 Litematica 时整个适配不会加载。

## 从源码构建

需要 JDK 25：

```bash
./gradlew build
```

构建产物位于 `build/libs/`。推送到 `main` 或提交 PR 时，GitHub Actions 会自动构建并上传产物。
